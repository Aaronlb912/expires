# Expires

A shop or household list of papers that die on a date. Warranty,
plates, permit, insurance, domain. See what is due in 30 days.

Drop `src/lib/` into a React app you already have. Host apps pass
`value` and `onChange`. The demo keeps the book in the browser.

The sample is Pell Street Motors. Names are fake. Emails end in
`.example`.

## Who it is for

Someone who already runs React and has a few papers with an expire
date. They finish "what is due, and where is the paper."

## Run the demo

```
npm install
npm start
```

Open http://127.0.0.1:48417/

Late papers sit on the desk as a mailed notice. Good thru is
